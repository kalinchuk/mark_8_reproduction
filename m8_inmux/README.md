# Mark-8 Improved Input Multiplexer (M8-INMUX+)

The original Mark-8 Input Multiplexer has three, major, limitations:

1. Only two input ports
2. No input from the bus
3. The 8263 and 8267 are hard to find

M8-INMUX+ solves all three.

Refer to the [M8-INMUX+ User's Guide](M8-INMUXUsersGuide.pdf) for assembly instructions, parts list and other information.
