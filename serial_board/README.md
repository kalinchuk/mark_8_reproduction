# Mark-8 Serial Board (M8-2SIO)

The M8-2SIO is a dual serial port PCB for the Mark-8 minicomputer.

**Note: This board requires the [M8-INMUX+](https://www.kalinchuk.com/product-page/mark-8-minicomputer-reproduction-m8-inmux-pcb)**

Refer to the [M8-2SIO User's Guide](M8-2SIOUsersGuide.pdf) for assembly instructions, parts list and other information.
